Connect GitHub Repo & Vercel App

Connect a GitHub repository so your team's Sessions, Games, Rosters & Drills sync across all coaches' phones and laptops automatically.

Quick 3-Step Vercel App Setup:
1. Create a GitHub repo (e.g., ambassadors-fc-app) and upload this index.html file.
2. Import that repo in Vercel → Deploy to get your live app URL.
3. Open your Vercel URL on iPhone/Android/iPad → tap Share → Add to Home Screen to install as an app!
